# ALGO/ART Tissue & Graphite V6 material source

These three files are copied unchanged from the exact upstream commit recorded in [PROVENANCE.md](PROVENANCE.md). Both upstream source and local copies are verified by CI, independent of the older V8 composition vendor pin. They are the actual material implementation (V5 torn outlines plus V6 pale tissue, seeded pigments, relief, graphite details), **not a CSS effect or a redraw of the source marker canvas**.

`js/tissue-worker.js` supplies Canvas via OffscreenCanvas and adapts the already-composed, time-windowed vector paths to `A.renderOil`'s recorder. The path-stub swatches have no geometry; they provide pigment colours when only a handful of partial strokes are visible. The AlgoAnimate adapter freezes the sheet's seed and palette once per sheet to avoid repigmenting everything when another voice changes. Swatches are collected in round-robin order across all eight voices. The V6 renderer remains unchanged; changing path order can still alter the random material details, so a composition-level frozen layer cache is the next separate visual experiment. ALGO Animate's original ALGO/ART V8 engine source under `vendor/algoart/` remains pinned and unmodified.

Material is computed asynchronously at preview resolution so the audio, timeline and main UI can continue at their normal cadence. Print export requests a higher-resolution re-render. The material PNG/video is raster; SVG exports deliberately retain the editable source vectors.
